# Installation

In etwa 10 Minuten kommen wir von null zu einem funktionierenden Bericht in Superset.
Für die Installation werden einige Abhängigkeiten und Kommandozeilenwerkzeuge benötigt.
Dieses Tutorial führt dich durch den Prozess und zeigt die Befehle.

Folgende Schritte werden erklärt:

- Die coasti-CLI installieren.
- Einen neuen coasti-Projektordner initialisieren.
- Unseren Superset-Docker-Container einrichten.
- Ein Demo-Content-Paket hinzufügen und dessen Setup ausführen, um die lokale Konfiguration vorzubereiten.
- Die Transformations-Pipeline ausführen, um die BI-Daten vorzubereiten und in Superset bereitzustellen.
- Die Frontend-Assets des Pakets in Superset hochladen.

:::note
In Produktivumgebungen richten wir coasti so ein, dass Superset auf einem anderen Rechner als die Transformationen läuft. Dadurch beeinträchtigen aufwendige Berechnungen der Daten-Pipeline nicht die Benutzererfahrung. Der Einfachheit halber verwenden wir in diesem Tutorial aber nur einen Host.
:::

## Voraussetzungen

- [docker](https://docs.docker.com/get-started/introduction/get-docker-desktop/)
- [git](https://git-scm.com/install/)
- [uv](https://docs.astral.sh/uv/getting-started/installation/) (wird in diesem Tutorial verwendet, die meisten Python-Paketmanager funktionieren aber ebenfalls)
- [Vollständige Anforderungen](../requirements.mdx): umfassenderer Überblick mit Hardware-Anforderungen und weiteren Details.


## Den coasti-Installer installieren

Der coasti-Installer ist ein kleines Python-Paket, das vorhandene Open-Source-Tools miteinander verbindet.
Damit können wir coasti-Projekte erstellen und verwalten, Versionskontrolle einrichten sowie Content hinzufügen oder aktualisieren.

Am einfachsten lässt sich der coasti-Installer mit uv installieren:

<Tabs groupId="os">
	<TabItem value="macos-linux" label="macOS / Linux" default>

        <Terminal>
        ```bash
        curl -LsSf https://astral.sh/uv/install.sh | sh

        uv tool install coasti
        ```
        </Terminal>

	</TabItem>

	<TabItem value="windows" label="Windows">

        <Terminal>
        ```powershell
        powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

        uv tool install coasti
        ```
        </Terminal>

	</TabItem>
</Tabs>

## Ein coasti-Projekt initialisieren

Alle Produkte, Inhalte und Metadaten, die du mit coasti verwendest, liegen in einem zentralen Ordner, einem _coasti-Projekt_.
Projekte werden mit `coasti init` initialisiert. Dafür musst du einen Ordnerpfad angeben.

Wir empfehlen einen absoluten und einfachen Pfad wie `/coasti`.
Das macht es etwas einfacher, Konfigurationen in Container einzubinden, da Pfade innerhalb und außerhalb der Container gleich verwendet werden können.

## Apache Superset installieren

Nachdem das coasti-Projekt eingerichtet ist, können wir Superset als Produkt hinzufügen.
Wir stellen ein [Docker-Image](https://github.com/coasti-org/superset_docker.git) mit allen wichtigen Bestandteilen bereit, das die Installation vereinfacht.

Zuerst stellt coasti einige Fragen dazu, wie das Produkt bezogen werden soll.
So kannst du auswählen, welchen Branch du verwenden möchtest (Produkte sind einfach Git-Repositories) und wie der Zugriff erfolgen soll, falls sich dein Produkt in einem privaten Repository befindet. Da Superset in einem öffentlichen Repository liegt, benötigen wir keine Authentifizierung.

<Terminal copyOnlyPrompts highlightPrompts typewriter typewriterSpeed={30}>
```bash
[prompt] cd /coasti
[prompt] coasti product add https://github.com/coasti-org/superset_docker.git

🎤 Install location:
[highlight]    products/superset_docker

🎤 Version control reference (git branch, tag or commit)
[highlight]    main

Added superset_docker in products.yml

🎤 Do you want to install superset_docker now?
[highlight]    No
```
</Terminal>


Nachdem Superset zu den coasti-Metadaten hinzugefügt wurde, werden wir aufgefordert, es zu _installieren_.
Wir können dies direkt tun (mit `y` oder `↵`) oder später über `coasti product install` installieren.

Dabei wird das Repository geklont und durch Fragen geführt, die zur Konfiguration von Superset benötigt werden.
Bei den meisten Fragen reicht es aus, die Standardauswahl durch Drücken von `↵` zu übernehmen.

Die Details deiner Antworten kannst du später in `/coasti/products/superset_docker/config/.env` nachsehen.

## Content-Frontend in Superset bereitstellen

Nachdem die Daten in Superset vorhanden sind, möchten wir die vorkonfigurierten Berichte in Superset anzeigen.
Normalerweise sind sie Teil des Content-Pakets und folgen dem Superset-Format, also YAML-Dateien mit einer bestimmten Struktur.

Im Demo-Content-Paket liegen diese YAML-Dateien unter `superset/frontend` (klicke [hier](https://github.com/coasti-org/linkfish_genesis_stats/tree/main/superset/frontend), um einen Eindruck von ihrem Aufbau zu bekommen).

Um die Assets in Superset hochzuladen, verwenden wir das zu coasti gehörende superset-io-Tool:

<Terminal copyOnlyPrompts highlightPrompts typewriter typewriterLineDelay={50}>
```bash
[prompt] cd /coasti/products/linkfish_genesis_stats
[prompt] coasti superset-io upload ./superset/frontend

INFO:superset_io:Connecting to Superset at: http://localhost:8088
INFO:superset_io:Connecting to Superset as: admin
Password [admin]: **doesnt appear when typing**
```
</Terminal>

Der Upload sollte nach wenigen Sekunden abgeschlossen sein und die Berichte sollten in Superset erscheinen:
