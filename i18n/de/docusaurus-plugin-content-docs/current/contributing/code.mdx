# Code beitragen

Du hast einen Fehler gefunden, eine Idee oder möchtest coasti verbessern? Beiträge sind willkommen.

## Issues und Pull Requests

Issues und Pull Requests für coasti-Tools eröffnest sammeln wir in den jeweiligen Repositories.
Die sind zu finden in der [coasti-Org auf GitHub](https://github.com/coasti-org).

Für einen Pull Request:

1. Forke das passende Repository und erstelle einen Branch.
2. Implementiere deine Änderungen.
3. Stelle sicher, dass die Tests und die Anforderungen an den Code-Stil des Repositorys erfüllt sind.
4. Öffne einen Pull Request und erkläre kurz, was sich geändert hat und warum.

Bei größeren Änderungen ist es meistens eine gute Idee, zuerst ein Issue zu eröffnen. So kann der Ansatz besprochen werden, bevor du mit dem Programmieren beginnst.

Wie immer: Halte die Änderungen fokussiert und orientiere dich am bestehenden Stil des Repositorys.

Danke fürs contributen!

## Hinweise zur Nutzung von KI

KI-Contributions sind zwar grundsätzlich willkommen, aber die Kommunikation sollte von einer echten Person übernommen werden. Wir werden wahrscheinlich Fragen zu deinem Pull Request haben und möchten, dass du die vorgeschlagenen Änderungen verstehst, damit wir ihre Auswirkungen gemeinsam besprechen können. Wenn ein Beitrag größtenteils mit KI erstellt wurde, erwarten wir außerdem, dass du dies von Anfang an offenlegst.

Wir legen Wert auf menschliche Kontrolle und Verantwortung: _KI ist ein Werkzeug, kein Akteur._
