# Zur Dokumentation beitragen

Die coasti-Dokumentation zu ergänzen ist einfach: Sie wird in **Markdown** geschrieben und verwendet zusätzlich einige Docusaurus-Funktionen.

## Überblick

1. Öffne eine `.mdx`-Datei im Ordner `docs/` oder lege eine neue an.
2. Schreibe deinen Inhalt mit Überschriften, Absätzen, Listen, Links und Codeblöcken.
3. Sieh dir die Seite lokal an. Wenn du dich nicht mit dem vollständigen Setup beschäftigen möchtest, reicht auch ein beliebiger Markdown-Viewer.
4. Committe deine Änderungen und öffne einen Pull Request in der [coasti-GitHub-Organisation](https://github.com/coasti-org).

Du musst weder React noch JavaScript kennen, um eine Seite zu verbessern. Fang einfach klein an und mach dir keine Sorgen, dass alles sofort perfekt sein muss – der Inhalt kann im Pull Request weiter verfeinert werden.
