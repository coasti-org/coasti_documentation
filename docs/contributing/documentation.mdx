# Contributing Documentation

Adding to the coasti docs is easy: documentation is written in **Markdown** with a few Docusaurus features on top.

## Quick overview

1. Open or create a `.mdx` file in the `docs/` folder.
2. Write your content using headings, paragraphs, lists, links, and code blocks.
3. Preview the site locally. If you do not want to tinker with the full dev setup, any markdown viewer will do.
4. Commit your changes and open a pull request in the [coasti GitHub organization](https://github.com/coasti-org).

You do not need to know React or JavaScript to improve a page. Start small, and do not worry about getting everything perfect—the content can be refined in the pull request.

## Helpful links

- [Docusaurus: Create Docs](https://docusaurus.io/docs/create-doc) explains how to get started.
- [Docusaurus: Markdown features](https://docusaurus.io/docs/markdown-features) covers the extra features available in `.mdx` files.
- [Markdown Guide: Basic syntax](https://www.markdownguide.org/basic-syntax/) is a handy Markdown reference.
- [Markdown viewers](https://www.markdownlang.com/intro/viewers.html) lists tools for previewing Markdown files.
