# Contributing Code

Found a bug, have an idea, or want to improve coasti? Contributions are welcome.

## Issues and pull requests

For coasti tools, open issues and pull requests in the respective repository.
You can find them in the [coasti org on GitHub](https://github.com/coasti-org).

For a pull request:

1. Fork the relevant repository and create a branch.
2. Implement your changes.
3. Make sure the repo's test suite and code-style requirements are met.
4. Open a pull request and briefly explain what changed and why.

For larger changes, it is usually a good idea to open an issue first so the approach can be discussed before you start coding.

As usual, keep changes focused and follow the style already used in the repository.

Thanks for helping improve coasti!

## Notes on AI usage

We welcome AI-generated contributions, but communication should be handled by a real person. We will likely have questions about your PR, and we need you to understand the proposed changes in order to discuss with us what the implications are. If a contribution is mostly AI-generated, we also expect this information to be disclosed upfront.

We value human oversight and accountability: _AI as a tool, not a contributor._
